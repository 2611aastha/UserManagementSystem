## Project Description

A User Management System developed using Node.js, Express.js, MongoDB, EJS, Sessions, and Multer.

The system provides role-based access control where only Admin users can manage user accounts.

## Features Implemented

### User Features

* User Registration
* User Login
* Upload Profile Picture
* User Dashboard
* Session Authentication

### Admin Features

* Admin Login
* View All Users
* Activate User
* Deactivate User
* Edit User Details
* Update Profile Picture
* Delete User
* Dashboard Statistics
* Logout Functionality

## Technologies Used

* Node.js
* Express.js
* MongoDB
* Mongoose
* EJS
* Express Session
* Multer
* Bootstrap

## How to Run the Project

### 1. Clone Repository

git clone <repository-link>

### 2. Open Project

cd UserManagementSystem

### 3. Install Dependencies

npm install

### 4. Start MongoDB

Make sure MongoDB service is running.

### 5. Start Application

node server.js

### 6. Open Browser

http://localhost:3000

## Default Admin

Admin account can be created directly in MongoDB with role = "admin".
